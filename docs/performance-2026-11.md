# Create: Large Lights 照射範囲・実照度の軽量化

検証日: 2026-11-11。変更前: `2c4b139a4acc7a26aa7134509e7bfe3b92d989f9`。

## 変更

- ビーム全体を遮る不透明面を確認し、その奥の形状走査を省く。閉じた部屋は六面を検証して範囲を絞る。部分的な壁では、対象区画全体への経路が塞がれると確認できた場合だけ除外する。
- CPUの遮光情報を照明間で共有し、空間の疎な部分をまとめて確認する。特殊形状は従来のVoxelShapeによる厳密な交差判定を使う。
- 実照度の対象候補を区画と4×4×4ブロックの小領域で絞る。通常のサーバー照度問い合わせにも同じ候補制限を使う。
- 射程・照射角・向きだけの変更では、光源位置が同じなら各ブロックへの遮蔽結果を再利用する。明るさだけの変更では照明の空間索引を作り直さない。
- 同期処理をサーバー負荷に応じて2〜8ms/tickに調整し、要求された区画を優先する。同じ照度データを再送せず、地形やFlywheelの再構築も減らす。
- 空中ビームの再走査を、照射先に関係するブロック変更に絞る。GPUが使う範囲では照明ごとのraycast生成を再利用する。

射程による減衰、照度の加算、1ブロック単位の照度、特殊形状・テクスチャの透過、1024×1024の影、GPU非対応時のCMS経路を維持。キャッシュは上限付き。

## 環境・条件

NVIDIA RTX 4060 / NVIDIA 595.99.02 / OpenGL 4.6、Minecraft 1.21.1、NeoForge 21.1.219、Create 6.0.10。本番GPU経路、1280×720、VSync無効、上限260fps、実際の明るさ有効。

81×81×66の試験空間に64灯、1,848個の特殊形状ブロックとCreateコピーキャット等を配置。全灯の位置・明るさ・照射角80°・設定射程を検証。絶対値はこの環境での測定で、ユーザーのワールドの性能を保証する値ではない。

## 距離だけを変えた比較

床上20ブロックから真下に照射し、床の位置を保って射程を変更。同じ視点（view=1）の値:

| 射程 | フレーム中央値 | 95パーセンタイル | 光のGPU処理中央値 | GPU描画灯数 |
|---|---:|---:|---:|---:|
| 128 | 5.138ms | 6.478ms | 1.345ms | 64 |
| 256 | 5.225ms | 6.525ms | 1.345ms | 64 |

両方とも設定確認後の最初の5秒間隔のログで実照度の更新待ちがゼロ（設定確認から3秒・4秒後）。初回計算が始まる正確な時刻を計測した値ではない。

変更前の同じ射程256試験では、tick=1000でも945区画が更新待ちだった。変更前は共有GPU形状が64MiB上限に達し、本番GPU描画灯数が0だったため、そのフレーム時間を同一描画経路の速度比としては比較しない。

## 広い照射範囲

床上60ブロックから斜めに64灯、射程256では、同じ視点の中央値7.129ms、95パーセンタイル8.510ms、GPU処理中央値3.602ms。GPUで64灯を描画。

実照度の更新待ちはtick=1000でゼロ。設定確認から38秒後のログで完了を確認した。初回の広域計算にはまだ数十秒かかり、瞬時には反映されない。多数の照明や複雑な地形を変更し続ける場合の待ち時間は残る。

## 首振り

床上60ブロック、64灯、射程256の首振りでは、view=1の中央値18.057ms、95パーセンタイル19.280ms。GPU描画64灯、毎フレーム64枚の影を更新し、影の更新間引きは行っていない。実照度の更新待ちはtick=1000でゼロ。

## 検証

- ユニットテスト75件、失敗・スキップ0。
- 本番GPU・照度デモ102チェック、失敗0。鉄格子、フェンス、上下ハーフブロック、階段、CreateコピーキャットのModelData更新を含む。
- 元の遮蔽処理と3,000本の光線を照合して一致。
- 点灯後・消灯後の双方で、同期された区画の4,096ブロック全てをサーバー照度と照合して一致。
- フェード、色・向き・遮蔽物変更、Flywheelと区画照度取得、資源の再読込、退出時の解放を確認。OpenGLエラー0。
- 光源から床まで256ブロック、設定射程300の長距離描画も8チェック、失敗0。
- GPU経路を強制的に無効化した単灯のCMS表面描画でも、3視点の実行が正常終了。

全modの特殊形状を網羅した検証ではない。特に独自ブロックエンティティ描画、Irisシェーダー、Sable構造物はこの実行環境で実地比較していない。

## 再現

```bash
mc-debug ./gradlew --no-daemon -PgpuDemo -PgpuMode=production -PgpuPerf -PgpuLights=64 -PgpuHeight=20 -PgpuAngle=vertical -PgpuRange=128 runClient
mc-debug ./gradlew --no-daemon -PgpuDemo -PgpuMode=production -PgpuPerf -PgpuLights=64 -PgpuHeight=20 -PgpuAngle=vertical -PgpuRange=256 runClient
mc-debug ./gradlew --no-daemon -PgpuDemo -PgpuMode=production -PgpuPerf -PgpuLights=64 -PgpuRange=256 runClient
```
