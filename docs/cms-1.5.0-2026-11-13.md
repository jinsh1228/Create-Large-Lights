# CMS 1.5.0対応

CMSの依存コミットを`4968723dba5030b7a6f6213def65f55c5f2cb059`（1.5.0）へ更新した。
バージョン番号だけでなく、`settings.gradle`がこのコミットのソースを使うことを確認する。
実験段階の照明・Sable APIを使用するため、CMSの互換性規約に従い実行時の範囲を`[1.5.0,1.6)`とした。

## 変更の確認

CMS 1.4.6の旧依存コミット`a7490922ea23bbf50aa1a39e3cd29b027c8b5ae0`からの差分を確認した。
`ConsoleView`のサーバー操作、追尾、`GroupView`のストロボ・チェイス、WASHなどが追加された。
CLLが登録する`FixtureOptics`・`WorldChanges`と、制御卓ページの公開APIの契約は変わっていない。
CLLが呼び出す描画フォールバックの旧インターフェイスもCMS側で維持されている。

CLLの処理コードとシェーダーは変更せず、既存の公開API連携・特殊形状の判定・照度計算・キャッシュを維持する。
CMS内部クラスへのMixinは追加していない。

## 検証

- CLLユニットテスト80件成功、失敗・スキップ0。
- CMSの`ApiCompatibilityTest`は3件成功。API記録を書き出す補助テスト1件は既定どおりスキップ。
- 実ゲームの描画・照度102項目成功。鉄格子・フェンス・ハーフブロック・Createコピーキャット、素材変更時のModelData更新、遮蔽物、向きと色の変更、フェード、Flywheel、資源再読込、退出時のGPU資源解放を含む。
- 制御卓・シーン・フェード・タイマー・街灯など57項目成功。
- 凹凸と特殊形状1,848個を含む81×81×66の部屋で128灯・射程256・実照度有効の検証に成功（11項目）。128灯すべてを描画し、view=1のフレーム中央値11.275ms、GPU投影中央値5.422ms。静止時の影再計算0回/frame、影キャッシュ512MiB、共有形状25,869,120 bytes。

実ゲームの検証環境: Minecraft 1.21.1 / NeoForge 21.1.219 / Create 6.0.10-280 / CMS 1.5.0（上記コミット）、NVIDIA RTX 4060、NVIDIA 595.99.02、OpenGL 4.6。
