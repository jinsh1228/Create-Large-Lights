# CMS 1.6.1対応と性能測定

CMS 1.6.1の既定ブランチの先頭 `c9d8d925a303a4588fc3ec4e7c3b55828f831bbf` に依存する。実験段階の照明・Sable APIを使うため、NeoForgeで宣言する対応範囲は `[1.6.1,1.7)`。マルチプレイではクライアントとサーバーのCMSを同じビルドに揃える。

CMSにランダム照準、交差スイープ、順送り点灯と、メディア再生ブロックや画面列挙のAPIが加わった。CLLの制御卓では固定、スイープ、円運動、追尾から選ぶ。外部から未対応の動きが設定された場合は固定として扱う。動きの判定には公開APIの `GroupView.Motion` を使う。

CMSはSableで移動した照明も実位置に基づいて並べるようになった。CLLでは、動きや配色が並び順に依存するときにだけ順序を求め、両方が必要なら同じ結果を使う。グループの灯数を取得するのは、配色に分割またはグラデーションを使う場合に限る。

更新前後の測定はRTX 4060、Minecraft 1.21.1、NeoForge 21.1.219、Create 6.0.10-280で行った。128灯、射程256、特殊形状1,848個、実照度有効の同一シナリオを1280×720、VSync無効、上限260fpsで比較した。

```bash
__GL_THREADED_OPTIMIZATIONS=0 mc-debug ./gradlew --no-daemon -PgpuDemo -PgpuMode=production -PgpuPerf -PgpuLights=128 -PgpuRange=256 runClient
```

| 指標 | 更新前 1.5.0 | 更新後 1.6.1 | 更新後の再測定 |
|---|---:|---:|---:|
| 静止視点1のフレーム中央値 | 11.22 ms | 10.89 ms | 10.86 ms |
| 同95パーセンタイル | 12.97 ms | 12.66 ms | 12.88 ms |
| 同GPU投影の中央値 | 5.42 ms | 5.41 ms | 5.43 ms |
| 照度同期の待ちが初めて0になった観測時点 | tick 800 | tick 900 | tick 800 |
| その時点までの処理区画数 | 190 | 216 | 188 |

全試行で128灯すべてが描画され、静止視点1・2では影の再計算は0回。影キャッシュは512 MiBだった。初回の照度同期は100 tick間隔の観測で、試行ごとに処理区画数も変動したため、差の原因をCMS更新に特定できない。描画時間に大きな変化はなかった。測定は統合サーバー上で行い、外部サーバーやIris、Sableを使う環境での性能は別途検証が必要。

クリーンビルド成功。CLLのユニットテスト86件、CMSのAPI互換性テスト3件、特殊形状・実照度の実ゲーム検証102項目、制御卓・フェード・タイマー等57項目が成功した。CMSのAPI記録を生成する補助テスト1件は既定どおりスキップ。
